# SWYNEX Final Data Analytics Project

## Retail Sales Data Analysis

### 1. Project Overview
This project analyzes retail sales data to identify sales trends, top-performing products, and important business insights. It combines data cleaning, exploratory data analysis (EDA), and an interactive Power BI dashboard.

### 2. Dataset Information
- **Dataset:** Online Retail II (2009–2010)
- **Source:** UCI Machine Learning Repository
- **Domain:** Retail Sales Analytics

### 3. Tools and Technologies
- Python
- Pandas
- Data Visualization
- Exploratory Data Analysis (EDA)
- Microsoft Power BI
- GitHub

### 4. Project Workflow
1. Cleaned the retail dataset and removed duplicate records.
2. Checked missing values and prepared the data for analysis.
3. Performed EDA to identify sales patterns and top-performing products.
4. Created an interactive Power BI dashboard with KPIs, charts, and filters.
5. Summarized the key business insights.

### 5. Key Business Insights
- Total sales were approximately 9.51 million in the dataset's recorded currency.
- November 2010 was the highest-sales month in the analysis.
- The United Kingdom contributed approximately 8.16 million in sales.
- WHITE HANGING HEART T-LIGHT HOLDER was the top product by sales value in the analysis.
